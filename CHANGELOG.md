# Changelog

## 1.0.0 — 2026-10-01

First public release of Traymio for Windows.

- Floating, optionally topmost file tray with up to 300 items.
- Collect files and folders using drag/drop, file/folder pickers, and clipboard references.
- Copy-only outgoing drag payloads, selected-item transfer, and drag-all control.
- Duplicate detection, unavailable-item handling, and one-level undo for remove/clear.
- Ctrl+Alt+T show/hide shortcut, notification-area icon, and Explorer reveal.
- Temporary in-memory tray; no saved shelves, startup entries, or app network requests.
- Executable, portable ZIP, checksums, English/Hindi guides, and Windows build checks.

This release is unsigned. Automated checks validate data payloads and UI handlers; live Explorer dragging, clipboard integration, notification-area behavior, hotkey conflicts, network paths, and mixed-DPI configurations require manual validation.
