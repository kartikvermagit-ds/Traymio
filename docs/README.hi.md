# Traymio — Hindi guide

Alag folders ki files ek chhoti floating tray mein jama karo, phir saath mein drag ya copy karo.

**[App download](https://github.com/kartikvermagit-ds/Traymio/releases/latest/download/Traymio.exe)** · [Windows ZIP](https://github.com/kartikvermagit-ds/Traymio/releases/latest/download/Traymio-Windows.zip) · [English](../README.md)

## Kaise chalayen

1. `Traymio.exe` kholo. Installer ya administrator access ki zaroorat nahi hai.
2. File Explorer se files/folders tray mein drag karo. Alag folders se aur items add kar sakte ho.
3. Green **Drag all files out** button ko pakadkar destination folder mein chhodo.
4. Kuch files chahiye toh Ctrl/Shift ke saath rows select karke unhe drag karo.
5. Ya **Copy all / Copy selected** dabao aur Explorer mein **Ctrl+V** karo.

**+ Files**, **+ Folder** aur **Paste files** se bhi items add kar sakte ho. Duplicate paths skip hote hain.

## Originals aur tray ka farq

Original files apni jagah rehti hain. Tray mein sirf unke paths hote hain, backup copies nahi. **Remove** aur **Clear tray** se disk ki files delete nahi hoti. **Undo / Ctrl+Z** se last removal/clear restore kar sakte ho.

Source file ko bahar se move ya delete karne par tray entry unavailable ho sakti hai. Use nayi location se dobara add karo.

**Hide se tray chalti rehti hai. X ya Exit se app band aur temporary list clear ho jati hai.** Is version mein saved shelves ya automatic Windows startup nahi hai. Ek window mein maximum 300 items hain.

## Useful controls

- **Ctrl+Alt+T:** running tray show/hide.
- **Escape / Hide:** notification area mein hide.
- **Tray icon double-click:** app dobara kholo; right-click se Exit.
- **Keep on top:** tray ko dusri ordinary windows ke upar rakho.
- **Double-click item:** Explorer mein uski location dekho.
- **Ctrl+A / Ctrl+C / Ctrl+V:** select all, copy, aur Explorer se copied files add karo.
- **Delete:** selected tray references hatao; original file delete nahi hoti.

Shortcut kisi aur app ne use kiya ho toh notification-area icon se tray kholo. Icon Windows ke hidden-icons arrow ke andar bhi ho sakta hai.

## Limitations

Sirf disk par existing files/folders supported hain. Plain text, web links, clipboard screenshots aur virtual email attachments is version mein supported nahi hain. Destination app ka drag/drop support matter karta hai. Normal aur administrator apps ke beech Windows drag/drop rok sakta hai.

App offline hai aur tray paths save nahi karti. **Copy** karne par file references Windows clipboard par jate hain. App unsigned hai, isliye Windows publisher warning dikha sakta hai.

Automated checks pass hain, lekin Explorer ke saath live drag/drop, clipboard paste, hotkey aur different display setups ko apne PC par try karna hoga.

Uninstall: app Exit karo, phir uska folder delete kar do.
